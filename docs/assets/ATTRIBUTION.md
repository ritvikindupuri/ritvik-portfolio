# Asset attribution

Official service icons used in the system architecture diagram come from
[Simple Icons](https://simpleicons.org/) and are dedicated to the public
domain under CC0:

- Cloudflare Pages
- Supabase
- GitHub
- OpenAI
- Google Gemini
- Resend

Visitor and Edge Functions icons are simple generic marks drawn for this
diagram. The header logo is the site favicon from `public/favicon.ico`.
